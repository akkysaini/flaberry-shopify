# Shopify Flow Automations — Flaberry Storefront & Marketplace

## 1. Overview
This document specifies the recommended and configured **Shopify Flow** automation workflows for the Flaberry Storefront and Multi-Vendor Marketplace. These automations streamline operational logistics, order tagging, delivery slot routing, and notifications without interfering with Webkul MultiVendor order assignment.

---

## 2. Priority Workflows

### Workflow 1: Order Pincode & Delivery Slot Extraction & Tagging
- **Trigger:** `Order created`
- **Condition:** Order contains line item custom properties `Delivery Date` or `Delivery Time Slot` or `Pincode`.
- **Action:**
  - Extract delivery pincode from shipping address or line item properties and add tag: `Pincode-{{ shipping_address.zip }}`
  - Extract delivery date and add tag: `Deliver-{{ line_item.properties['Delivery Date'] }}`
  - If `Delivery Time Slot` contains "Midnight", add tag: `Slot-Midnight`
  - If `Delivery Time Slot` contains "Fixed Time", add tag: `Slot-FixedTime`
  - If `Delivery Time Slot` contains "Standard", add tag: `Slot-Standard`
- **Purpose:** Enables warehouse, florists, and delivery fleet dispatchers to instantly filter orders in Shopify Admin by pincode and delivery time window.

---

### Workflow 2: High-Value & Luxury Gifting Alert
- **Trigger:** `Order created`
- **Condition:** `Order total_price_gross_amount >= 5000` (INR 5,000+)
- **Action:**
  - Add tag: `High-Priority-Celebration`
  - Send internal email / Slack notification to Senior Florist Lead and Operations Manager.
  - Add internal order note: `Priority Luxury Order - Requires senior florist quality check and premium ribbon packaging.`
- **Purpose:** Ensures premium floral arrangements and multi-tier milestone cakes receive executive quality control before dispatch.

---

### Workflow 3: Multi-Vendor Order Routing Flagging
- **Trigger:** `Order created`
- **Condition:** Order contains products from multiple vendors (`line_items.vendor`).
- **Action:**
  - Add tag: `Multi-Vendor-Order`
  - Flag order for coordinated delivery handoff so separate florist and bakery items arrive together or in sync for the recipient.
- **Safety Boundary:** Does not override Webkul vendor commissions or payout records.

---

### Workflow 4: Fresh Floral & Perishable Inventory Re-order Alert
- **Trigger:** `Inventory quantity changed`
- **Condition:** `Product vendor == 'Flaberry Central'` AND `Inventory quantity < 10`
- **Action:**
  - Send reorder alert to Central Floral Procurement team.
  - Tag product: `Low-Stock-Perishable`
- **Purpose:** Prevents overselling of fast-moving fresh stems (Red Roses, Lilies, Orchids) during peak festive rushes (Valentine's, Mother's Day, Diwali).

## 3. App Compatibility Matrix

| App | Flow Integration Status | Conflict Prevention |
|---|---|---|
| **Shopify Search & Discovery** | Complementary | Flow uses product tags generated by Search & Discovery filters |
| **Judge.me Reviews** | Native Integration | Flow sends review request triggers after order fulfillment |
| **Webkul MultiVendor** | Isolated | Flow operates on Shopify order tags; Webkul handles seller dashboard |
| **Translate & Adapt** | Compatible | Customer language code is passed to Flow notification templates |
| **Shopify Markets** | Native | Flow conditions respect multi-currency `total_price` attributes |
